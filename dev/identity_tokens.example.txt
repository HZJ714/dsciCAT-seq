# dev/identity_tokens.example.txt — 推送闸 G1 的**结构型**身份模式（一行一个正则，# 开头为注释）
#
# 为什么公开树里只有模式、没有字面量：本仓曾是私有仓，转 public / 归档 Zenodo 之后
# 任何"明文用户名、同事名、集群项目号、机房挂载根"都会永久可检索，所以 G1 改成
# 按**形态**匹配。这些模式不 spelled-out 任何真实标识，但能抓出所有同类串（包括
# 我们还没想到的账号名），比原来的明文清单更严。
#
# 想要逐字精确监看（本工作环境用）：把真实 token 一行一个写进
#   dev/identity_tokens.txt          ← 已在 .gitignore 里，不会被推送
# 闸会在它存在时自动叠加；不存在时只用下面的模式。

# 个人/机器家目录
/home/[^/\s<>"'`,)]+
/Users/[^/<>"\s"'`,)]+
/data/users/[^/<>"\s"'`,)]+
# 集群项目号形态（P2xZxxxxxNxxxx 这类）
\bP[0-9]{2}Z[0-9]{5,7}N[0-9]{4}\b
# 机房绝对挂载根形态（只匹配 hwfs*sz1 前缀，不写出全名）
\bhw[f]s[sz][0-9]+/
# 真实邮箱（排除 <obj>@meta.data 这类 R S4 槽位、排除 GitHub noreply）
[A-Za-z0-9._%+-]{3,}@(?!users\.noreply)(?:[A-Za-z0-9-]+\.)+(?:cn|com|org|net|edu|io|de|uk)\b
# 共享名形态（形如 _xx_yy_nn 的站点卷名）
\b_[a-z]{2}_[a-z]{2}_[0-9]{2}\b
