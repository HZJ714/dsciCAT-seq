# The single live generator for each notebook (agreed 2026-11-11)

The root README used to say "every notebook is generated by its
`figX/build_figX_notebook.py`", which contradicted `dev/README.md` (which puts the
live generators for fig4 / figS4 / figS6 in `dev/`, and keeps fig6 / fig7 in their
package roots). This table is the one authoritative statement; both READMEs point here.

Rule of thumb: when a generator exists both in a package root and in `dev/`, the copy
marked live in this table is the only one to edit — the other is a historical draft.

Check after editing a live generator:

```bash
python3 dev/build_fig4_notebook.py        # or figX/build_figX_notebook.py
git diff --stat figX/Figure_X.ipynb       # regenerated cell sources vs committed notebook: expect 0
```

⚠ Never maintain two copies. The repo previously carried both `fig6/build_fig6_notebook.py`
and `dev/build_fig6_notebook.py` with different content, which left readers guessing which
one produced the notebook.
